# LearnHub

Образовательная демо-платформа на HTML, CSS и JavaScript.

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в современном браузере.
3. Для удобной разработки можно открыть папку в VS Code и запустить через расширение Live Server.

## Возможности
- Каталог школьных предметов и уроков.
- Отметка завершённых уроков и начисление баллов.
- Тесты с проверкой ответов и начислением баллов.
- Регистрация, вход и выход.
- Личный кабинет, учебная статистика и рейтинг.
- Сохранение демо-данных в localStorage браузера.

## Важно
Это учебный frontend-прототип. Пароли сохраняются в localStorage без серверной защиты и хеширования. Не используй настоящие пароли и личные данные. Для реального публичного сервиса нужна серверная авторизация, база данных, хеширование паролей, HTTPS и серверная проверка результатов. Рейтинг в этой версии локальный: разные устройства и браузеры не синхронизируются.
